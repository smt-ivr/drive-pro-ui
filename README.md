# Drive Pro – ממשק משתמש

אפליקציית הווב של Drive Pro: מדביקים קישור לקובץ או לתיקייה ב-Google Drive, בוחרים מה להעתיק, והכול מועתק לדרייב שלך – כולל תיקיות שלמות עם כל תתי-התיקיות.
רצה כ-Cloudflare Worker עם Static Assets בכתובת `https://smti.uk/drive-pro/`, ומדברת עם ה-API שבריפו [`drive-pro`](https://github.com/smt-ivr/drive-pro).

## יכולות

- **סייר קבצים** – כניסה לתתי-תיקיות, פירורי לחם, סינון לפי שם, מיון, תצוגת רשימה/רשת.
- **העתקת תיקיות שלמות** – רקורסיבית, עם או בלי שמירת מבנה התיקיות.
- **כמה קישורים בבת אחת** – אחד בכל שורה.
- **העתקה מקבילית** עם פס התקדמות, עצירה, וניסיון חוזר לפריטים שנכשלו – לאותן תיקיות יעד.
- **הודעות שגיאה ברורות** – קובץ חסום להעתקה, אין הרשאה, אין מקום בדרייב וכו'.
- **היסטוריית העתקות** עם קישורים לתיקיות.
- **מצב כהה**, תמיכה מלאה במובייל, קיצורי מקלדת (`Ctrl+K`, `Ctrl+A`, `Backspace`, `Esc`).
- **התחברות עמידה** – חלון קופץ, ואם הוא נחסם (נפוץ במובייל) מעבר אוטומטי להפניה מלאה. הטוקן מתחדש לבד לפני שהוא פג.

## מבנה

```
public/                 הקבצים שמוגשים לדפדפן (ללא שלב build)
  index.html
  css/app.css           עיצוב – משתני צבע, מצב בהיר/כהה, רספונסיבי
  js/app.js             בקר האפליקציה (DOM ואירועים)
  js/api.js             לקוח API + ניהול סשן (רענון טוקן, ניסיונות חוזרים)
  js/copy-job.js        מנוע ההעתקה (רקורסיה, מקביליות, כשלונות, ביטול)
  js/config.js          כתובת ה-API והגדרות
  js/lib/*.js           עזרים טהורים: קישורים, פורמט, תור משימות, DOM, אחסון
  js/ui/toast.js        התראות
src/worker.js           מגיש את public/ תחת /drive-pro + כותרות אבטחה (CSP וכו')
test/                   בדיקות (node --test)
```

כל טקסט שמגיע מגוגל (שמות קבצים וכו') נכנס ל-DOM כטקסט בלבד – אין `innerHTML` עם תוכן חיצוני.

## פיתוח

```bash
npm install
npm run dev        # http://localhost:8788/drive-pro/
npm test
npm run check      # בדיקות + בדיקת build של ה-Worker
```

כדי לעבוד מול API מקומי (`npm run dev` בריפו `drive-pro`), מריצים פעם אחת בקונסול של הדפדפן:

```js
localStorage.setItem('drivepro.apiBase', JSON.stringify('http://localhost:8787/drive-pro/api'))
```

## פריסה

```bash
npm run deploy
```

ה-Worker הזה מוגדר על `smti.uk/drive-pro*`, וה-Worker של ה-API על הנתיב הספציפי יותר `smti.uk/drive-pro/api*`.
